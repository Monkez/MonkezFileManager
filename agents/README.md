# Tài Liệu Dành Cho AI Agents

Đọc các file trong thư mục này cùng `rule.md` và `docs/` trước khi sửa dự án.

- `project-status.md`: trạng thái kỹ thuật hiện tại, quyết định kiến trúc và các giới hạn cần giữ.

Tài liệu người dùng nằm trong `docs/`. Nội dung trong `agents/` tập trung vào ngữ cảnh triển khai để agent tiếp theo không phải suy luận lại từ đầu.
